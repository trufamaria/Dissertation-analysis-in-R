# Dissertation Analysis in R

Analysis code for my doctoral dissertation, *Need for Chaos and Hostile Content Online Sharing: A Comparative Analysis of Mediating Pathways in the United States and Brazil* (Texas Tech University, 2026).

## What the code does

The dissertation tests whether need for chaos predicts the sharing of hostile content online, and which pathways explain the link. It compares survey data from the United States and Brazil using parallel mediation models and structural equation modeling.

## Contents

- `R/`: scripts for data preparation and the SEM and mediation models, built with lavaan, haven, and semPlot
- `python/`: scripts for text classification with large language models

## Data

Survey data is not included because of participant privacy. The scripts show the variable names and model specifications, so the analysis can be repeated with similar data.
